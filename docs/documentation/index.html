Architecture ouverte.

La page est structurée pour ajouter de nouvelles sous-pages sans modifier l’application autonome.

Données localesCompteurs, onglets, historique et préférences sont enregistrés dans le navigateur.
Sauvegardes JSONConfigurations globales, onglets et réglages avancés peuvent être importés ou exportés.
ThèmesPalette, couleurs favorites et CSS personnalisé restent portables dans les sauvegardes.
Structure GitHub PagesChaque sous-page possède son propre dossier et son fichier index.html.
