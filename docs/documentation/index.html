Prendre en main votre espace

Un tableau pour chaque suivi.

Le modèle organise les tuiles. Le tableau enregistre vos observations quotidiennes.

1. Choisir ou créer un tableau

Depuis l’accueil, ouvrez Bipo, dupliquez-le comme point de départ ou créez un tableau vierge. Renseignez son nom et la maladie ou le besoin de suivi. Une copie reprend les réglages, sans les observations ni les notes.

2. Configurer les onglets et les tuiles

Ajoutez vos onglets, puis des tuiles. Choisissez un compteur d’événements, une valeur / échelle, ou une confirmation de prise. Définissez l’icône, la couleur, l’unité, l’incrément, les limites et la largeur : 1/3, 1/2 ou pleine ligne.

Les flèches ↑ ↓ changent l’ordre. L’aperçu montre la disposition. « Enregistrer et ouvrir » applique le modèle au tableau. Les indicateurs et consignes médicales sont à convenir avec votre soignant.

3. Faire le suivi quotidien

Choisissez le jour. Un clic incrémente un compteur ou confirme une prise ; les valeurs et échelles ouvrent une saisie. Le bouton ✎ sert à corriger, déclarer une non prise ou noter un ressenti. « — » signifie non renseigné.

Le bouton ↶ annule la dernière saisie. Le menu ⋮ conserve les réglages rapides des tuiles. « Configurer » ouvre l’éditeur complet et reprend la configuration utilisée dans le tableau.

4. Faire évoluer le modèle

Renommer ou élargir une tuile conserve ses saisies. Retirer une tuile du modèle conserve ses anciens événements et sa définition dans la sauvegarde complète du tableau. Les tableaux archivés disparaissent de l’accueil, mais peuvent être restaurés en cochant « Afficher les tableaux archivés ».

5. Exporter et sauvegarder

« Exporter le modèle » produit un fichier de configuration sans valeurs, notes ou prescriptions personnelles. « Importer un modèle » crée toujours un nouveau tableau et ne remplace pas un suivi existant.

Pour les observations, ouvrez le tableau puis Bilan ou Préférences → Sauvegarde complète. Le JSON complet contient les données du suivi : conservez-le dans un endroit privé. Les notes et contacts sont exclus du bilan texte tant que vous ne les cochez pas.

Où sont mes données ?

Dans le stockage de ce navigateur. Chaque tableau a son propre suivi. Bipo conserve sa clé de stockage existante. Il n’y a pas de compte, de synchronisation entre appareils ou de chiffrement applicatif. Effacer le stockage du navigateur peut supprimer modèles et suivis : exportez-les avant toute opération de nettoyage.

Les rappels fonctionnent dans une page ouverte. L’outil ne pose pas de diagnostic, ne modifie pas les doses et n’est pas surveillé par une équipe médicale.
